# RankedTools artwork

The bundled covers are hand-drawn developer artwork supplied by the project owner on 2026-10-05, with AccSaber covers and a replacement Sync cover supplied on 2026-11-12. They replace the earlier AI-generated covers. Each supplied image is used unchanged as a 512 × 512 PNG.

The files in this directory are mirrored at the project root, where the QMOD packaging script reads them. Keep both copies synchronized when changing artwork.

| File | Playlist |
|---|---|
| `beatleader_notplayed.png` | BeatLeader Not Played |
| `beatleader_toimprove.png` | BeatLeader To Improve |
| `beatleader_ppgain.png` | BeatLeader PP Gain |
| `scoresaber_notplayed.png` | ScoreSaber Not Played |
| `scoresaber_toimprove.png` | ScoreSaber To Improve |
| `scoresaber_ppgain.png` | ScoreSaber PP Gain |
| `beatleader_clan_toconquer.png` | Maps to Conquer fallback |
| `sync.png` | Sync (replacement cover) |
| `accsaber_notplayed.png` | AccSaber Not Played |
| `accsaber_toimprove.png` | AccSaber To Improve |
| `accsaber_ppgain.png` | AccSaber AP Gain (supplied Simple Mode cover) |
| `accsaber_clan.png` | Reserved for later AccSaber clan support; not packaged |

Maps to Conquer continues to prefer the actual clan icon fetched from BeatLeader, independently for every clan playlist. The bundled clan cover is used only when that icon is unavailable.

The files in `references/` are retained as historical brand references; they are not the current bundled covers.
