# RankedTools 0.1.20

Adds account selection to Mod Settings. Each leaderboard has a name search with five results per page, showing names, avatars when available, countries, ranks and numeric IDs. Selecting a result saves its canonical numeric ID and display name. Profile links and existing numeric IDs can be entered in the same field. BeatLeader aliases and verified linked Quest/Steam/Oculus IDs resolve to the primary profile; ScoreSaber vanity links use its v2 vanity endpoint. ScoreSaber name searches need at least three characters.

The optional **Use signed-in BeatLeader account** button reads BeatLeader's published, typed `LoggedInPlayerId` export and validates its public profile before saving. It is compatible with the API published in BeatLeader 0.8.73; missing mods, missing exports and logged-out states show a search fallback. The header-only conditional-dependencies 0.3.0 helper adds no required BeatLeader dependency or runtime library. No credentials or authentication tokens are accessed. ScoreSaber uses public account search/profile lookups.

Saved IDs remain compatible with previous configuration files. Settings displays the chosen name and can reveal its ID or clear the selection. Reopening settings updates saved profile names without selecting a different account. Search/profile results require explicit selection, including single matches. A request revision prevents stale HTTP replies, older pages and cancelled searches from changing the current results. Lookup failures preserve the previous selection. Account and avatar HTTP work runs off the main thread; configuration changes and Unity image uploads run on the main thread. Replaced avatar textures are destroyed, and downloads, image dimensions and timeouts are bounded. Unsupported or unavailable avatars leave the account selectable using its text details.

Account changes take effect on the next recommendation refresh. Local attempts continue to use the IDs captured when gameplay starts. Turn off **Record local attempts** when viewing somebody else's profile. Existing attempt files are preserved, including when clearing an account. A previously configured secondary/linked ID is preserved until a new selection is made; old attempt files are not silently reassigned.

Validation: 2,079 recommendation, history, chart, clan and account regression checks and 40 playlist-writer checks passed. The Quest arm64 build passed. The release manifest schema, 1.40.8_7379 game target, 10 archive entries, current-build binary hash, preserved bundled artwork and matching versioned/generic QMOD copies were verified. Live BeatLeader search, alias and linked-ID lookup and ScoreSaber search/profile responses were checked against the parsing assumptions. The signed-in export and settings layout have not been exercised on a headset.
